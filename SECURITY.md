# Security policy

Sentinel is pre-1.0 software intended for local development and evaluation. It is not yet
hardened for production; see [docs/security/SECURITY.md](docs/security/SECURITY.md) for the
implemented controls and known limitations, and
[docs/architecture/THREAT_MODEL.md](docs/architecture/THREAT_MODEL.md) for the threat model.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** button
(Security tab → Advisories) rather than in a public issue. Include steps to reproduce and the
affected version or commit. Reports that show a way to execute an action that was never
authorized, or to bypass a hard policy block, are treated as highest priority.

## Supported versions

Only the latest commit on `main` receives fixes.
